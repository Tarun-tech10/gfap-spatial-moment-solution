# GFAP spatial moment reconstruction — solution

Final solution for reconstructing GFAP burden moments from microscopy fields.
`solution.py` is the end-to-end pipeline (dense-target fusion, density-map CNN,
exact rectangle integration, calibration, submission writing); `APPROACH.md`
explains the method and the experiments behind it.

Development code: https://github.com/Tarun-tech10/gfap-spatial-moment-reconstruction

The dataset and the submission file are not included.
